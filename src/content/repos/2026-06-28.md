# 2026-06-28 · 今日热门 AI 项目

## 1. [deepset-ai/haystack](https://github.com/deepset-ai/haystack) ★25762

开源 AI 编排框架，用于构建生产级 RAG、Agents、语义搜索等 LLM 应用

**能力**：Haystack 提供模块化管道和 agent 工作流，支持显式控制检索、路由、记忆和生成。它集成了多种文档存储、检索器、大模型，可用于构建搜索推荐系统中的知识检索和问答 agent。

**借鉴价值**：
- 可直接复用的 RAG 管道组件，如检索器、排序器，用于电商商品搜索和问答
- 支持 Agent 与检索结合的工作流编排，可借鉴其架构实现带记忆的多轮推荐 agent
- 提供生产环境部署的最佳实践，如文档分块、嵌入优化，可加速推荐系统原型开发

## 2. [labring/FastGPT](https://github.com/labring/FastGPT) ★28677

基于 LLM 的知识平台，开箱即用的数据处理、RAG 检索和可视化 AI 工作流编排

**能力**：FastGPT 提供可视化 Flow 编排，支持构建复杂的问答系统，包括数据导入、向量化、对话管理。它可以直接应用于商品知识库问答、客户服务 agent，并支持多轮对话和上下文管理。

**借鉴价值**：
- 其可视化工作流编排思路可用于快速搭建推荐系统的 Agent 流程，如多路召回、排序融合
- 内置的数据处理和 RAG 检索模块，可直接用于构建电商领域的商品知识库检索
- 支持与外部模型和工具集成，可扩展为搜索推荐 agent 的核心引擎

## 3. [agentscope-ai/agentscope](https://github.com/agentscope-ai/agentscope) ★27241

生产就绪的 Agent 框架，提供事件系统、人机协同和多 Agent 管理

**能力**：AgentScope 2.0 包含统一的事件总线、灵活的 Agent 生命周期管理和内置分布式支持。可用于构建多 Agent 协作的搜索推荐系统，如用户画像 Agent、商品召回 Agent、排序 Agent 协同工作。

**借鉴价值**：
- 其事件驱动架构可借鉴用于实现 Agent 间的异步通信，适用于推荐系统的多阶段流水线
- 提供多 Agent 协作的模板，可复用为推荐系统中不同职责的 Agent（如检索、过滤、排序）
- 支持将人类反馈集成到 Agent 决策中，可用于搜索推荐的用户交互优化

## 4. [volcengine/OpenViking](https://github.com/volcengine/OpenViking) ★26118

专为 AI Agent 设计的上下文数据库，通过文件系统范式统一管理记忆、资源和技能

**能力**：OpenViking 提供层次化的上下文传递和自我进化能力，可作为 Agent 的长期记忆和知识库，支持用户记忆、Agent 记忆和知识库问答场景。可用于搜索推荐系统中的用户画像长期存储和动态更新。

**借鉴价值**：
- 其层次化上下文管理可应用于推荐系统的用户画像构建，实现渐进式个性化
- 提供 Agent 记忆的基准测试和实现，可借鉴其记忆更新机制来提升推荐 agent 的持续性理解
- 文件系统范式简化了上下文组织，可用于管理推荐场景的多模态信息（如商品、用户行为）

## 5. [f/prompts.chat](https://github.com/f/prompts.chat) ★164441

全球最大的开源 prompt 库，适用于 ChatGPT、Claude 等，可自托管

**能力**：收集了社区贡献的大量 prompt，涵盖各种任务。可用于设计和优化搜索推荐 agent 的提示工程，如商品描述生成、用户意图理解、推荐理由生成等。

**借鉴价值**：
- 可直接检索和适配其中关于推荐、搜索、总结等任务的 prompt 模板
- 提供 prompt 工程的最佳实践，有助于设计出更精准的 agent 指令
- 自托管功能允许企业内部构建专用 prompt 库，保护数据隐私
