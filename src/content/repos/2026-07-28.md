# 2026-07-28 · 今日热门 AI 项目

## 1. [CopilotKit/CopilotKit](https://github.com/CopilotKit/CopilotKit) ★36322

构建 Agent 原生应用的前端框架，支持生成式 UI、共享状态和人机协作。

**能力**：提供 React、Angular、Vue 等框架的 Agent 集成 SDK，支持 Generative UI 协议 AG-UI，实现对话驱动的动态界面生成。内置共享状态管理和 Human-in-the-loop 工作流，可快速搭建聊天式推荐交互或 Agent 工作台。适用于电商导购、搜索助手等需要自然语言交互的场景。

**借鉴价值**：
- 可直接复用 `@copilotkit/react-core` 等前端组件，为推荐系统增加对话式交互层。
- 生成式 UI 的思想可借鉴用于搜索结果页的动态推荐卡片生成。
- 人机协作工作流可应用于需要用户反馈的推荐排序或解释场景。

## 2. [OpenHands/OpenHands](https://github.com/OpenHands/OpenHands) ★82347

自托管的 Agent 开发控制中心，统一管理多个编码 Agent。

**能力**：基于 TypeScript 的 Agent Canvas，支持本地、远程、云端运行 OpenHands、Claude Code 等 Agent，并提供 ACP 协议兼容。提供自动化流水线、多 Agent 协作和沙箱环境管理，适合构建复杂的多步骤 AI 任务编排系统。

**借鉴价值**：
- 多 Agent 协作架构可直接参考，用于设计推荐系统的查询理解、检索、排序等 Agent 分工。
- 自动化流水线（Prebuilt Automations）的模板可复用于数据处理和模型更新流程。
- ACP 协议的设计思路有助于规范内部 Agent 通信，提升系统模块化。

## 3. [open-webui/open-webui](https://github.com/open-webui/open-webui) ★146998

功能丰富的自托管 AI 平台，内置 RAG 推理引擎，支持 Ollama 和 OpenAI API。

**能力**：Python 编写的 Web UI，可完全离线运行，集成 Ollama 等本地 LLM 和兼容 OpenAI 的 API。提供内置 RAG 引擎、插件扩展系统、多模态支持，适合作为企业内部的 LLM 服务和知识库问答平台。

**借鉴价值**：
- 可直接用作电商搜索推荐团队的内部 LLM 服务平台，提供 RAG 能力增强商品知识库的问答。
- 插件机制可扩展自定义推荐算法接口，快速搭建原型。
- 其 RAG 实现可作为搜索增强推荐的参考实现，尤其是文档处理和向量检索部分。

## 4. [agentscope-ai/QwenPaw](https://github.com/agentscope-ai/QwenPaw) ★29209

轻量级个人 AI 助手，易于部署，支持多聊天应用和扩展能力。

**能力**：基于 Python 的个人 AI 助手框架，支持一键部署到本地或云端，可接入多种聊天前端（微信、钉钉等）。提供可扩展的命令系统和记忆管理，适合快速构建领域特定的对话式 Agent。

**借鉴价值**：
- 可快速搭建面向用户或内部人员的推荐助手，通过扩展命令集成商品查询、个性化推荐等功能。
- 其多聊天应用支持模式可借鉴，低成本实现多渠道覆盖（如电商小程序内的 AI 导购）。
- 记忆管理模块对实现推荐系统中的用户画像长期记忆有参考价值。

## 5. [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) ★93592

通过穴居人式极简语言风格，节省 Agent 输出 tokens 达 65%。

**能力**：可为 Claude Code、Codex 等 30+ Agent 安装的技能插件，使 Agent 输出变为精简的“穴居人”风格，但保持代码、命令等精确不变。支持多种压缩级别，可大幅降低 LLM 调用成本。

**借鉴价值**：
- 极简输出思路可直接应用于推荐系统 Agent 的对话响应，降低每次推荐交互的 token 消耗。
- 可借鉴其进度级别（grunt level）设置，提供不同简洁程度的推荐解释。
- 这种风格化压缩方法可用于训练或提示工程，优化推荐结果的文本生成。

## 6. [santifer/career-ops](https://github.com/santifer/career-ops) ★61885

多 Agent 求职系统，自动扫描职位、结构化评分并定制简历。

**能力**：JavaScript 实现的 AI 求职代理，能自动爬取职位列表，用 A-F 评分准则对职位打分（1.0-5.0），并据评分结果定制求职简历和申请材料。支持在本地 AI 编码 CLI 中运行，展示了多 Agent 任务编排和自动化决策流程。

**借鉴价值**：
- 多 Agent 协作流程可参考，用于构建“需求解析-商品召回-评分排序-推荐解释”的推荐管道。
- 结构化评分准则的设计思想可直接迁移至商品与用户匹配度的打分体系。
- 自动化文档定制功能启发生成个性化推荐理由或广告文案的 Agent 实现。
