# 2026-08-28 · 今日热门 AI 项目

## 1. [shareAI-lab/learn-claude-code](https://github.com/shareAI-lab/learn-claude-code) ★75534

从零构建类 Claude Code 的 agent harness，教学 Agent 基础设施

**能力**：用 Python 实现一个极简 agent 循环，包含模型调用、工具执行、上下文管理，强调“Agency 来自模型，产品=模型+harness”。

**借鉴价值**：
- 提供清晰的最小 Agent 架构，可直接参考其核心循环逻辑来设计电商推荐 Agent 的决策流程
- 展示了工具调用和状态管理的最佳实践，适合快速验证新想法
- 代码精简，适合团队培训或作为自定义 Agent 脚手架的起点

## 2. [browser-use/browser-use](https://github.com/browser-use/browser-use) ★111539

让 AI Agent 能像人一样操作浏览器，自动化完成网页任务

**能力**：提供 Python 库，基于 Playwright 控制浏览器，可将自然语言指令转化为浏览器操作（点击、输入、导航），支持多标签、文件上传等，可集成任意 LLM。

**借鉴价值**：
- 可直接用于电商场景：商品页抓取、竞品价格监控、库存查询、自动下单等
- 为 Agent 提供成熟的浏览器工具接口，避免重复开发 DOM 操作逻辑
- 其状态表示和任务分解设计可借鉴到需要网页交互的推荐/搜索 Agent 中

## 3. [HKUDS/nanobot](https://github.com/HKUDS/nanobot) ★47491

超轻量 Python 个人 AI agent 框架，带 WebUI、工具、记忆、MCP

**能力**：支持多代理工作流、记忆管理、MCP 协议、自动化任务，可自托管，插件式架构，易扩展。

**借鉴价值**：
- 可直接复用它基于 MCP 的工具管理机制，方便接入电商平台 API（如商品搜索、订单查询）
- 其记忆模块对构建个性化推荐对话 Agent 有参考价值
- 轻量架构适合快速搭建原型，并可与现有推荐服务组合

## 4. [zhayujie/CowAgent](https://github.com/zhayujie/CowAgent) ★46709

多模型多渠道的开源超级 AI 助手与 Agent Harness

**能力**：支持主动规划任务、控制计算机、创建技能、长期记忆，可接入主流 IM 平台（微信、钉钉等），跨 Web 和本地运行。

**借鉴价值**：
- 其多渠道接入能力适合构建面向多渠道的电商客服/导购 Agent
- 技能（Skills）创建机制可借鉴用于封装商品推荐、优惠查询等业务能力
- 长期记忆和知识库实现有助于打造个性化购物助手

## 5. [ollama/ollama](https://github.com/ollama/ollama) ★179625

本地运行和管理开源大模型（如 DeepSeek、Qwen）的轻量工具

**能力**：提供跨平台安装、模型拉取、量化、推理服务，支持 OpenAI 兼容 API，可与现有 Agent 框架集成，可嵌入自有系统。

**借鉴价值**：
- 可直接在电商推荐系统中以本地 API 形式部署 LLM，降低推理成本并保护数据隐私
- 支持模型热切换和多种量化级别，便于 A/B 测试不同生成式推荐模型
- 提供 Python/JS 库，可无缝集成到 Agent 工作流中作为模型后端

## 6. [pingcap/tidb](https://github.com/pingcap/tidb) ★40476

分布式 SQL 数据库，兼具事务、分析和向量搜索能力

**能力**：支持 HTAP，内置向量搜索（通过 TiFlash 或扩展），水平扩展，强一致，可存储商品、用户、向量等数据。

**借鉴价值**：
- 其向量搜索能力可作为电商推荐系统中 embedding 检索的存储层，替代专用向量库
- 事务 + 分析混合支持可用于实时特征计算和推荐结果存储
- 云原生架构适合高并发、大规模电商场景，避免数据孤岛

## 7. [Mintplex-Labs/anything-llm](https://github.com/Mintplex-Labs/anything-llm) ★65325

本地优先的全栈 AI 应用，支持文档问答、Agent 和多用户

**能力**：提供完整的 RAG 流水线，支持多种文档导入、嵌入模型和向量数据库，可构建本地知识库，具备 Agent 能力和细粒度权限管理。

**借鉴价值**：
- 可直接用于构建电商内部知识库（商品文档、政策、操作手册）问答系统
- 其 RAG 实现支持多种向量库和 LLM，方便与现有推荐系统的向量检索结合
- 多用户和权限设计适合企业级部署，可作为搜索推荐系统的辅助工具

## 8. [rasbt/LLMs-from-scratch](https://github.com/rasbt/LLMs-from-scratch) ★103937

用 PyTorch 从零实现类 GPT 的 LLM，含预训练和微调代码

**能力**：提供完整代码和教程，逐步实现 Transformer、注意力机制、训练和微调，并支持加载预训练权重。

**借鉴价值**：
- 深入理解 LLM 结构和训练过程，有助于设计更有效的生成式推荐模型

- 可作为团队内训教材，提升算法团队对 LLM 底层原理的掌控力
