## 1. [bytedance/deer-flow](https://github.com/bytedance/deer-flow) ★84461

字节开源的超级智能体编排框架，支持子智能体、记忆、沙箱与技能扩展。

**借鉴价值**：
- 可直接借鉴其多智能体编排和记忆管理架构，用于构建推荐系统中的多步推理与用户意图理解 Agent。
- 其沙箱和工具调用机制适合封装搜索、推荐 API 作为 Agent 可调用的工具。
- 技能扩展系统可用于定义领域特定的推荐策略或数据分析技能。

## 2. [shareAI-lab/learn-claude-code](https://github.com/shareAI-lab/learn-claude-code) ★79302

从零构建类 Claude Code 的 Agent 引擎，深入讲解 Agent 与 Harness 分离设计。

**能力**：教学项目，用 Python 从 0 到 1 实现一个 nano claude code 风格的 agent harness，阐明 Agency 来自模型训练而 Harness 负责环境交互，帮助理解 agent 核心机制。

**借鉴价值**：
- 其“模型提供能力，Harness 提供环境”的思路有助于设计搜索推荐系统的 Agent 基础设施。
- 可借鉴其最小化 Harness 实现，快速搭建自定义 Agent 原型，集成推荐模型和工具。
- 对 agent 内部工作流的讲解有助于优化现有 agent 架构的可靠性和可扩展性。

## 3. [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) ★115372

通过“穴居人式”极简表达压缩 LLM 输入输出，大幅降低 token 消耗。

**能力**：提供 skill 和 proxy，让 AI agent 输出更简洁、读取更少，实测可减少 33% 输入 token、54% 成本，同时保持代码准确。支持 30+ agents，含 blocks 模式。

**借鉴价值**：
- 可直接集成 token 压缩策略到推荐系统的 LLM 调用链，降低推理成本。
- 其“压缩提示”思路可用于生成式推荐的物品描述、用户评论总结等场景的 prompt 优化。
- 低成本高收益，适合在高频调用 LLM 的电商 Agent 中部署。

## 4. [QwenLM/qwen-code](https://github.com/QwenLM/qwen-code) ★28740

**能力**：开源 agentic 框架，支持 OpenAI、Anthropic、Gemini、Qwen 等协议，集成 Auto-Memory、Auto-Skills、SubAgents、Agent Teams 和 MCP，可在终端、IDE、桌面、浏览器运行。

**借鉴价值**：
- 其多协议切换和本地模型支持，为推荐系统 Agent 提供灵活的 LLM 后端选择。
- Auto-Memory 和 Auto-Skills 机制可借鉴用于构建用户长短期记忆和领域技能库。
- MCP 集成方式可直接用于连接商品数据库、搜索引擎等外部工具。

## 5. [huginn/huginn](https://github.com/huginn/huginn) ★50154

**能力**：Ruby 构建的事件驱动 agent 系统，Agent 之间通过事件流传播，可抓取网站、监控 RSS/邮件/Webhook，执行自定义 JavaScript/Liquid 逻辑，支持 OpenAI 兼容 API 进行文本处理。

**借鉴价值**：

- 其网页抓取和多源数据聚合思路可借鉴构建商品信息、评论监控 Agent。
- 自定义 Agent 和事件流设计有助于搭建轻量级数据管道，为推荐模型提供实时特征。
