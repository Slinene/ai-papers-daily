# 2026-08-07 · 今日热门 AI 项目

## 1. [bojieli/ai-agent-book](https://github.com/bojieli/ai-agent-book) ★33815

系统讲解AI Agent设计原理与工程实践，含工具、规划、多Agent等

**能力**：全书覆盖Agent核心概念、记忆机制、工具调用、规划与推理、多Agent协作等，提供95个配套实验和代码，支持多种大模型。

**借鉴价值**：
- 可借鉴Agent = LLM + 上下文 + 工具的核心公式，设计搜索推荐中的对话式Agent
- 记忆机制章节可直接用于构建用户长期偏好记忆模块
- 多Agent协作思路可用于广告竞价、推荐重排等场景的协同Agent架构

## 2. [affaan-m/ECC](https://github.com/affaan-m/ECC) ★238350

Agent harness性能优化系统，提供技能、记忆、安全等组件

**能力**：为Claude Code等AI编码代理提供统一的技能管理、记忆系统、安全护栏和性能调优，可扩展至其他Agent场景。

**借鉴价值**：
- 记忆系统实现可复用于用户行为序列的持久化与召回
- 技能管理框架可用于封装推荐策略、广告投放规则等可调用工具
- 安全护栏设计可防止Agent生成不合规广告内容或不当推荐

## 3. [CherryHQ/cherry-studio](https://github.com/CherryHQ/cherry-studio) ★49935

AI生产力工作室，统一访问多种LLM并支持自主Agent

**能力**：集成300+预设助手、自主Agent工作流、多模型运行时切换，支持OpenAI、Gemini等API，提供可视化Agent配置。

**借鉴价值**：
- 多模型统一访问层可直接用于A/B测试不同LLM在推荐解释中的效果
- 自主Agent工作流可参考构建商品推荐助理，自动处理用户查询
- 助手市场模式可启发构建可插拔的广告创意生成Agent集合

## 4. [f/prompts.chat](https://github.com/f/prompts.chat) ★166825

最大的开源提示库，收集并分享社区提示词

**能力**：提供大量可复用的对话提示模板，覆盖多种任务场景，支持自托管和组织私有提示库。

**借鉴价值**：
- 直接复用对话式推荐、商品比较、广告文案生成的提示设计
- 学习提示结构模板，优化搜索意图澄清和推荐理由生成的prompt
- 借鉴优秀提示的写法，提升LLM在电商场景下的指令遵循能力
