# 2026-08-12 · 今日热门 AI 项目

## 1. [shareAI-lab/learn-claude-code](https://github.com/shareAI-lab/learn-claude-code) ★73897

从零构建类 Claude Code 的 Agent Harness，强调模型+外壳的工程实现。

**能力**：通过 Python 实现一个极简的 agent 外壳，涵盖工具调用、上下文管理、bash 执行等核心模块。项目强调智能来自模型训练，外壳仅提供基础设施，并提供从 0 到 1 的构建教程。

**借鉴价值**：
- 深入理解 agent 产品架构，将 harness 思想用于搜索推荐 agent 的设计，分离推理与工具执行
- 可借鉴其工具调用模式（如 bash 工具），实现推荐系统的自定义工具（召回，排序 API）
- 了解如何高效管理长上下文，用于处理用户多轮对话和搜索历史

## 2. [HKUDS/nanobot](https://github.com/HKUDS/nanobot) ★46868

超轻量、自托管的 Python 多 Agent 框架，含 WebUI、记忆、MCP 等。

**能力**：支持多 agent 协作、工具调用、长期记忆和知识库，提供 WebUI 和 CLI。集成 MCP 协议，可连接外部工具和数据源。轻量级设计易于嵌入现有系统。

**借鉴价值**：
- 直接用于构建推荐系统的多 agent 架构，如用户分析 agent、召回 agent、排序 agent 分工协作
- 利用 MCP 集成内部推荐 API，实现 agent 与业务系统的无缝工具调用
- 内存模块可保存用户偏好和会话上下文，提升个性化体验

## 3. [zhayujie/CowAgent](https://github.com/zhayujie/CowAgent) ★46464

开源超级 AI 助手，具备任务规划、工具技能、自进化记忆的 Agent Harness。

**能力**：支持任务规划与分解，可控制计算机和外部服务，创建运行 Skill，构建个人知识库和长期记忆。多模型、多渠道，轻量可扩展。

**借鉴价值**：
- 任务规划能力可应用于多步骤推荐流程（如先筛选、再比较、后推荐）
- 工具和 Skill 机制允许封装推荐算法为可调用单元，方便 agent 编排
- 长期记忆可用于存储用户历史行为，实现推荐策略的持续优化

## 4. [pingcap/tidb](https://github.com/pingcap/tidb) ★40420

分布式 SQL 数据库，原生支持事务、分析和向量搜索，适合 Agent 工作负载。

**能力**：提供水平扩展的 HTAP 能力，内置向量搜索（近似最近邻），支持混合查询（全文+向量）。兼容 MySQL 生态，ACID 保证。

**借鉴价值**：
- 作为推荐系统的向量存储引擎，支持 embedding 召回和相似商品检索
- 利用混合搜索能力，实现多路召回（文本匹配+向量相似）的一体化查询
- 分布式架构可支撑电商大促时的海量请求，避免数据孤岛

## 5. [ollama/ollama](https://github.com/ollama/ollama) ★178308

本地运行和管理开源 LLM（如 Kimi、DeepSeek、Qwen）的简易工具。

**能力**：提供 REST API，支持多平台，可快速部署 LLM 服务。集成 Claude Code、OpenClaw 等 agent 框架，简化模型推理。

**借鉴价值**：
- 低门槛部署用于推荐系统的文本理解模型（query 意图识别、评论分析）
- 作为推荐 agent 的本地大脑，保护数据隐私，降低推理成本
- 与 agent 框架结合，快速搭建原型，验证生成式推荐思路

## 6. [Mintplex-Labs/anything-llm](https://github.com/Mintplex-Labs/anything-llm) ★64627

全栈本地优先的 AI 应用，集文档聊天、Agent、多用户于一体。

**能力**：支持 RAG，可导入多种文档，内置 agent 功能，可配置 LLM 和向量数据库。提供多用户管理和权限控制。

**借鉴价值**：
- 快速构建商品知识库问答，提升客服和导购体验
- 利用其 agent 能力搭建电商 RAG 原型，探索 LLM 与检索的结合方式
- 多租户架构可为不同店铺或业务线隔离数据，适合平台型电商

## 7. [browser-use/browser-use](https://github.com/browser-use/browser-use) ★108851

让网站对 AI agent 可访问，自动化在线任务。

**能力**：提供浏览器环境下的 agent 工具包，支持网页导航、数据提取、表单填写等，可与各种 LLM 集成。

**借鉴价值**：
- 用于电商竞品数据监测 agent，自动抓取价格、评价等信息
- 模拟用户浏览行为，测试推荐系统的在线效果和曝光率
- 构建交互式推荐调试 agent，直接在浏览器中操作分析推荐结果
