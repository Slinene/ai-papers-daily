## 8. [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) ★113517

通过“穴居人式”表达削减 coding agent 65% token 消耗。

**能力**：提供 Go 编写的 skill + proxy，让 AI agent 以极简语言输出和读取，保持代码准确。测试显示输入 token 减少 33.2%，成本降低 54%，输出 token 大幅减少。已被 Adobe Research 引用。

**借鉴价值**：
- 其 token 削减思路可直接用于推荐系统中 LLM 生成内容、解释或对话，降低 API 成本。
- 可借鉴其通过改变 prompt 风格优化性能而不损失效果的方法，对大规模线上服务很有价值。
- 该技术可集成到任何 LLM 调用管道，作为成本优化模块。
