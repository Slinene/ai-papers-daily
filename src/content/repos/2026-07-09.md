- 可借鉴其内存优化思路，在 Agent 推理环节提升效率。

## 8. [headroomlabs-ai/headroom](https://github.com/headroomlabs-ai/headroom) ★57954

上下文压缩层，大幅减少发送给 LLM 的 token，降低成本且不损失回答质量。

**能力**：提供库、代理和 MCP 服务器，在数据进入 LLM 前进行内容感知压缩。对 JSON 数据可节省 60-95% token，编码场景节省 15-20%。支持可逆压缩，确保信息不丢失。本地运行，保护隐私。

**借鉴价值**：
- 可集成到推荐 Agent 中压缩商品列表、用户特征等上下文，降低 token 消耗和延迟。
- 其压缩思路可借鉴用于日志、检索结果的长文本优化，提升 Agent 吞吐。
- 帮助在有限上下文窗口内容纳更多相关信息，间接提高推荐准确性。
