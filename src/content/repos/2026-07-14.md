# 2026-07-14 · 今日热门 AI 项目

## 1. [BerriAI/litellm](https://github.com/BerriAI/litellm) ★53505

统一 100+ LLM API 的 Python SDK/网关，支持成本控制与负载均衡

**能力**：LiteLLM 提供 Python SDK 和可自托管的 AI 网关，允许通过统一的 OpenAI 格式调用 100 多个 LLM API，包括 Anthropic、Azure、VertexAI 等。内置成本跟踪、速率限制、故障转移和负载均衡机制，适合生产环境中管理和路由多个模型。

**借鉴价值**：
- 可直接用作推荐系统后端的多 LLM 路由层，统一 API 格式并简化模型接入
- 利用成本跟踪和负载均衡功能，优化大规模 API 调用的资源分配
- 可借鉴其架构实现自定义模型网关，集成到 Agent 流程中进行模型选择与管理

## 2. [run-llama/llama_index](https://github.com/run-llama/llama_index) ★50827

领先的文档 Agent 和 OCR 平台，用于构建基于 LLM 的知识检索系统

**能力**：LlamaIndex 提供数据连接器、向量存储索引、查询引擎和高级 RAG 模式，允许通过自然语言查询结构化和非结构化数据。支持 Agent 集成，能够构建复杂的检索增强生成管道。

**借鉴价值**：
- 可直接用于构建商品知识库的 RAG 引擎，实现智能搜索与问答
- 其索引和检索策略可借鉴用于个性化推荐中的内容理解与召回
- 提供的 Agent 模块可集成到多步骤推理流程，增强推荐系统的交互能力

## 3. [labring/FastGPT](https://github.com/labring/FastGPT) ★28941

基于 LLM 的 AI Agent 构建平台，提供开箱即用的数据处理和 RAG 可视化工作流

**能力**：FastGPT 支持可视化 Flow 编排工作流，集成数据处理、模型调用和 RAG 检索，可快速构建复杂问答系统。提供 Docker 部署，适合企业级应用，无需大量配置即可启用知识库问答能力。

**借鉴价值**：
- 可复用其工作流引擎设计，构建搜索推荐中的 Agent 流水线
- 其 RAG 实现可作为构建商品问答系统的模板，加速原型开发
- 开箱即用的特性允许快速验证结合 LLM 的交互式推荐方案

## 4. [agentscope-ai/agentscope](https://github.com/agentscope-ai/agentscope) ★27820

生产就绪的 Agent 框架，提供事件总线、人机循环等基本抽象

**能力**：AgentScope 支持构建多 Agent 系统，通过事件驱动架构实现 Agent 间协作，内置人机交互组件。适合开发需要复杂决策和工具调用的 Agent 应用，例如对话式推荐或动态策略调整。

**借鉴价值**：
- 可直接用于构建推荐系统的多 Agent 协作架构（如检索、排序、对话 Agent）
- 事件总线设计可解耦 Agent 间通信，提升系统灵活性和可扩展性
- 人机交互模块可用于构建需要用户反馈的个性化推荐 Agent

## 5. [rasbt/LLMs-from-scratch](https://github.com/rasbt/LLMs-from-scratch) ★99044

从零实现 ChatGPT 类 LLM 的教学代码，逐步讲解预训练与微调

**能力**：提供用 PyTorch 从零构建 GPT 类模型的全套笔记本代码，涵盖预训练、微调及大模型权重加载。帮助读者深入理解 LLM 内部机制，并具备小型实验能力。

**借鉴价值**：
- 理解 LLM 注意力、位置编码等机制，有助于优化模型在推荐系统中的应用
- 可借鉴微调策略，针对商品描述或用户行为序列训练定制模型
- 提供小型模型训练示例，可用于快速实验新想法
