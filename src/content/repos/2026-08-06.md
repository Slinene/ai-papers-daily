## 5. [rtk-ai/rtk](https://github.com/rtk-ai/rtk) ★74934

通过压缩命令行输出降低 LLM token 消耗的 CLI 代理

**能力**：以极低延迟过滤和压缩 shell 命令输出，支持 100+ 命令，将长输出转换为结构化摘要，可节省 60-90% 的 token，适用于所有基于命令的 Agent 场景。

**借鉴价值**：
- 直接集成到搜索推荐 Agent 的 shell 工具调用链路中，显著降低上下文 token 成本，尤其适用于高频日志分析、数据导出等操作
- 其输出压缩逻辑可泛化到其他长文本压缩，为 Agent 记忆管理提供启发
- 单二进制、零依赖，方便嵌入现有 Agent 系统
