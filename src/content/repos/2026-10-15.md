# 2026-10-15 · 今日热门 AI 项目

## 1. [ollama/ollama](https://github.com/ollama/ollama) ★183198

本地运行和管理开源大模型，支持Kimi、DeepSeek、Qwen等。

**能力**：Ollama 提供跨平台的本地模型运行时，支持 macOS、Windows、Linux 和 Docker，提供 Python/JS 库，可接入 Claude Code、Codex 等编码代理。它简化了模型下载、量化、推理和服务化，适合私有化部署 LLM。

**借鉴价值**：
- 可以直接使用 Ollama 作为本地推理引擎，降低电商场景中 LLM 调用成本，保护用户数据隐私
- 借鉴其模型管理、量化和并发推理实现，优化自有推理服务架构
- 通过 Ollama 统一接入多个开源模型，快速实验搜索推荐中的生成式排序和商品文案生成

## 2. [HKUDS/nanobot](https://github.com/HKUDS/nanobot) ★49042

超轻量 Python 个人 AI Agent 框架，集成工具、记忆、MCP 和多智能体。

**能力**：nanobot 提供 WebUI、工具调用、长期记忆、多智能体工作流和自动化任务，支持 MCP 协议。它是一个自托管的轻量框架，方便定制和扩展，适合快速搭建 Agent 应用。

**借鉴价值**：
- 可直接复用其 Agent 工具调用和记忆管理模块，实现个性化推荐中的用户长期偏好追踪
- 借鉴多智能体编排模式，构建召回、排序、对话等模块协作的搜索推荐 Agent 系统
- 学习其 MCP 集成方式，将商品、广告、用户数据以工具形式暴露给 LLM

## 3. [zhayujie/CowAgent](https://github.com/zhayujie/CowAgent) ★47406

开源个人 AI 助手与 Agent Harness，支持多智能体、多模型、多渠道。

**能力**：CowAgent 是一个参考实现 Agent Harness 工程，支持主动任务规划、控制计算机和外部服务、创建技能、构建个人知识库和长期记忆、组建多智能体团队，并可通过自我进化成长。

**借鉴价值**：
- 借鉴其 Agent Harness 架构，设计电商搜索推荐中可扩展的 Agent 编排层
- 利用其多智能体协作和知识库管理能力，构建商品知识问答与导购助手
- 参考其多模型多频道接入方案，统一管理不同 LLM 提供商和交互入口

## 4. [pingcap/tidb](https://github.com/pingcap/tidb) ★40642

分布式 SQL 数据库，原生支持事务、分析和向量搜索。

**能力**：TiDB 提供 ACID 分布式事务、水平扩展、高可用，并内置向量搜索能力，支持 SQL 进行相似度检索。它适合处理不可预测增长的 Agent 工作负载，消除数据孤岛。

**借鉴价值**：
- 可以直接使用 TiDB 的向量搜索功能，作为推荐系统的向量存储和相似商品检索引擎
- 利用其分布式事务保证商品、订单、用户画像数据的一致性，同时支持实时分析
- 借鉴其混合事务与分析处理（HTAP）架构，统一推荐系统的在线服务和离线训练数据存储

## 5. [browser-use/browser-use](https://github.com/browser-use/browser-use) ★118017

开源浏览器智能体库，支持 AI 浏览器自动化和托管 Agent API。

**能力**：browser-use 提供 Python 库让 LLM 控制浏览器完成自动化任务，如页面导航、表单填写、数据抓取。同时提供 Browser Use Cloud 的 stealth 浏览器和托管 Agent API。

**借鉴价值**：
- 可直接用于电商商品页爬取、竞品价格监控和自动化购物流程测试
- 借鉴其浏览器操作抽象和 LLM 交互设计，构建自动化商品信息采集 Agent
- 利用其云端 stealth 浏览器 API，实现大规模分布式数据采集，规避反爬

## 6. [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) ★126620

将代码库、文档、SQL schema 等转化为可查询知识图谱。

**能力**：Graphify 通过本地确定性 AST 解析，将任意代码库及其文档、数据库模式、配置文件、PDF 等转换为知识图谱，支持 Claude Code、Cursor、Codex 等 CLI 工具查询，不依赖向量存储。

**借鉴价值**：
- 借鉴其确定性图构建方法，将商品描述、类目、属性和用户行为构建为领域知识图谱
- 使用图谱查询代替纯向量检索，提升搜索推荐的可解释性和复杂关系推理能力
- 复用其“无向量存储”的图索引思路，降低基础设施成本，同时保留结构化关系

## 7. [alibaba/open-code-review](https://github.com/alibaba/open-code-review) ★47235

阿里开源混合架构代码评审工具，结合确定性规则与 LLM Agent。

**能力**：OpenCodeReview 采用混合架构：确定性流水线处理多语言规则（如 NPE、线程安全、XSS、SQL 注入），LLM Agent 提供行级精确评论，兼容 OpenAI 和 Anthropic 接口，已在阿里大规模实战检验。

**借鉴价值**：
- 借鉴其确定性规则与 LLM 混合架构，在搜索推荐中融合规则引擎与大模型生成式重排
- 参考行级评论的思路，构建推荐理由的细粒度归因，增强模型解释性
- 学习其多语言规则引擎实现，可以迁移到广告审核、商品合规检查等场景
