## 4. [rtk-ai/rtk](https://github.com/rtk-ai/rtk) ★73711

CLI 代理，通过压缩输出减少 LLM token 消耗 60-90%。

**能力**：截取 shell 命令输出，进行智能压缩（如 ls 转树格式，cat 提取结构）后再传递给 LLM。支持 100+ 命令，零依赖 Rust 二进制，延迟 <10ms，有效降低 agent 与 LLM 交互的成本。

**借鉴价值**：
- 可直接作为推荐 agent 与基础系统交互时的中间层，压缩日志、搜索结果等输出，降低 token 费用。
- 压缩算法可应用于推荐系统中用户行为序列的总结，减少 LLM 输入。
- 轻量级优化组件，可嵌入到现有 agent 管道中。
