# 2026-07-31 · 今日热门 AI 项目

## 1. [letta-ai/letta](https://github.com/letta-ai/letta) ★24034

有状态AI Agent平台，提供高级记忆与自学习能力，支持长期交互。

**能力**：Letta Agent SDK 支持构建具有多种记忆（如长期记忆、工作记忆）的有状态 Agent，可通过 CLI、桌面应用、Slack 等渠道运行。模型无关，Agent 能执行任务并自我改进，内置技能和子代理机制，适用于需要持续学习和个性化交互的场景。

**借鉴价值**：
- 可借鉴其记忆架构，为推荐 Agent 引入用户长期兴趣建模和自适应学习。
- 提供的 Agent SDK 可直接用于构建自有推荐 Agent，管理对话状态和记忆。
- 技能和子代理机制可用于编排推荐流程中的多个子任务（如召回、排序），提高系统灵活性。

## 2. [bytedance/deer-flow](https://github.com/bytedance/deer-flow) ★78250

**能力**：整合子代理、记忆、沙箱、工具和技能，通过可扩展技能驱动，支持分钟到小时级别任务。提供消息网关协调多个子代理，适用于深度探索和高效研究流程，支持多种 LLM 后端。

**借鉴价值**：
- 子代理编排模式可直接用于推荐系统的多代理协作，例如分别负责用户画像、召回、排序等。
- 记忆和沙箱机制为构建安全、有状态的推荐推理环境提供参考。
- 技能扩展方式可用于将推荐算法封装为可调用工具，实现 Agent 驱动推荐。

## 3. [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) ★99248

将代码库、文档、SQL 架构等转化为可查询知识图谱的 CLI 工具。

**能力**：基于本地确定性 AST 解析生成知识图谱，每条边有解释，无需向量存储。可作为 Claude Code、Cursor 等编码助手的 skill，用于理解复杂项目结构与关系。

**借鉴价值**：
- 知识图谱构建方法可借鉴用于电商商品关联图谱、用户行为图谱的自动生成。
- 确定性解析思路可指导构建领域特定的实体关系抽取，提升图谱质量。
- 作为 Agent 技能集成，可辅助理解推荐系统内部依赖，用于调试和优化。

## 6. [huggingface/transformers](https://github.com/huggingface/transformers) ★163190

**能力**：提供数千预训练模型，统一接口进行推理和微调，支持 PyTorch、TensorFlow、JAX。覆盖自然语言处理、计算机视觉、语音等任务，持续集成最新模型架构。

**借鉴价值**：

- 支持多模态模型，为搜索推荐引入视觉信号提供便捷途径。
