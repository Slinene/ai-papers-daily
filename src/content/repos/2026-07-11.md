# 2026-07-11 · 今日热门 AI 项目

## 1. [ollama/ollama](https://github.com/ollama/ollama) ★175899

本地运行和管理开源大模型，提供REST API，支持Kimi、Gemma等。

**能力**：Ollama 是一个本地推理服务器，通过一条命令即可拉取和运行多种开源LLM，并提供兼容 OpenAI 的 REST API。它支持 GPU 加速，适合为 Agent 系统提供自托管的大模型后端，可被 Claude Code、OpenCode 等工具集成。

**借鉴价值**：
- 可直接作为电商搜索推荐系统中 Agent 的 LLM 后端，实现本地推理，降低 API 成本并保护数据隐私。
- 支持快速切换不同模型进行对比实验，便于在搜索推荐场景下评估不同 LLM 的生成和排序能力。
- 提供的 OpenAI 兼容 API 使现有框架（如 LangChain）可无缝对接，无需修改代码。

## 3. [MemPalace/mempalace](https://github.com/MemPalace/mempalace) ★57210

开源 AI 记忆系统，实现语义搜索和结构化记忆存储，96.6% Recall@5。

**能力**：MemPalace 以逐字方式存储对话历史，并通过语义搜索进行检索。它采用可插拔后端（默认 ChromaDB），将记忆组织为 people/projects 等层级结构，支持本地运行且无需 API 调用。

**借鉴价值**：
- 可直接用于电商 Agent 的用户会话记忆模块，实现长对话历史和用户偏好的精准检索，提升个性化推荐体验。
- 结构化记忆设计（wings/rooms/drawers）可借鉴用于组织商品知识图谱或用户画像，支持高效范围检索。
- 插件化后端设计允许替换为更适合推荐系统的向量数据库（如 Milvus），且与 LLM 的集成思路清晰，便于在生成式推荐中融入记忆上下文。

## 7. [pingcap/tidb](https://github.com/pingcap/tidb) ★40272

分布式 SQL 数据库，支持事务、分析和向量搜索，为 Agent 工作负载设计。

**能力**：TiDB 提供水平扩展、ACID 分布式事务、向量相似度搜索，兼具 OLTP 和 OLAP 能力。其内置的向量搜索功能可直接用于 AI 应用，避免多系统数据同步。

**借鉴价值**：
- 提供内置向量搜索能力，可直接作为推荐系统召回阶段的向量引擎，存储商品 embedding 并进行近邻检索。
- 支持混合查询（向量+标量过滤），适合电商推荐中的多条件召回，如“在某个品类下找相似商品”。
- 分布式架构适合高并发推荐服务，可承担特征存储和实时索引，减少系统复杂性。
