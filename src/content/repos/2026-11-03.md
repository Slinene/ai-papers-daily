# 2026-11-03 · 今日热门 AI 项目

## 1. [labring/FastGPT](https://github.com/labring/FastGPT) ★29981

基于LLM的知识库平台，提供RAG检索与可视化工作流编排。

**能力**：FastGPT 提供开箱即用的数据处理、模型调用和 RAG 检索能力，支持通过 Flow 可视化编排 AI 工作流，可快速构建复杂问答系统。基于 TypeScript 开发，支持 Docker 私有化部署。

**借鉴价值**：
- 可直接复用其 RAG pipeline（文档解析、向量化、检索）用于商品知识库问答和导购场景。
- 工作流编排器可作为推荐解释生成、多轮对话管理的参考架构。
- 支持 Docker 快速部署，适合快速搭建电商客服或智能导购 agent 原型。

## 2. [teableio/teable](https://github.com/teableio/teable) ★21951

将数据管理与AI工作流结合的AI电子表格，底层为PostgreSQL。

**能力**：提供类似电子表格的界面但底层是真正的 PostgreSQL 数据库，支持数据管理、AI 工作流和自定义应用构建。Agent 可以直接操作实时数据，适合业务场景。

**借鉴价值**：
- 可用于构建电商数据中台，支持商品、订单等结构化数据的实时查询与管理。
- 其 AI 工作流与数据紧密结合的设计，可借鉴用于让推荐 agent 直接操作数据库。
- 自托管且基于 PostgreSQL，方便与现有数据栈集成。

## 3. [trycua/cua](https://github.com/trycua/cua) ★31628

面向计算机使用agent的开源驱动、沙箱与基准测试套件。

**能力**：提供 Cua Driver 桌面自动化、Lume 本地 VM、CUA-S1 决策模型和 Cua Bench 评估，支持跨 OS 沙箱、训练、评估和数据生成，用于构建和评测 GUI 操作 agent。

**借鉴价值**：
- 可复现其沙箱环境用于安全地执行电商网站自动化操作（如价格监控、自动下单）。
- 基准测试和数据生成管线可借鉴用于构建推荐 agent 的交互数据收集与评测。
- 驱动层抽象有助于快速开发跨平台的数据采集 agent。

## 4. [rtk-ai/rtk](https://github.com/rtk-ai/rtk) ★85380

通过压缩、路由、过滤等管道降低LLM token消耗的CLI代理。

**能力**：单 Rust 二进制，零依赖，提供 agent 无关的 token 优化管道，可压缩 bash 输出等达到 60-90% token 减少，支持组合式处理。

**借鉴价值**：
- 可直接集成到现有 agent 中，减少 LLM 调用成本，尤其适用于高并发推荐搜索场景。
- 其可组合的压缩/过滤管道设计可借鉴用于优化 prompt 和上下文管理。
- 该工具可降低大规模 LLM 推理的运营开销。
