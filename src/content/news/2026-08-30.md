# 2026-08-30 · AI 行业动态

## 1. 智谱发布 GLM-5.3 系列开源模型

智谱 Z.ai 发布 GLM-5.3 系列开源模型，包括 GLM-5.3-Flash（320B 总参/18B 活跃，原生多模态，1M 上下文，MIT 许可）及全尺寸 GLM-5.3（744B/40B 活跃，优化 agentic coding 和网络防御）。超大 MoE 参数、1M 上下文配合 MIT 许可，直接对标国际主流开源模型。

- [not much happened today](https://news.smol.ai/issues/26-08-28-not-much/) `blog:smol-ai-news`

## 2. OpenAI 自研推理芯片 Jalapeño 基准结果公布

OpenAI 公布自研推理芯片 Jalapeño 的基准测试，与 NVIDIA GB200/GB300 相比，效率提升 1.5–1.9 倍，延迟降低 1.7–3.6 倍。此举显示 OpenAI 在降低对 NVIDIA 依赖、优化推理成本上的实质性进展。

- [not much happened today](https://news.smol.ai/issues/26-08-25-not-much/) `blog:smol-ai-news`

## 3. NVIDIA 提出 Agent 评估新指标 Skill Lift

NVIDIA 研究指出传统技能检查难以预测 agent 的实际有用性，并提出新指标 Skill Lift 来更准确衡量 agent 能力提升。该指标针对 agent harness 优化，可能影响未来 agent 评估标准。

- [not much happened today](https://news.smol.ai/issues/26-08-24-not-much/) `blog:smol-ai-news`

## 4. Anthropic 胜诉五角大楼黑名单案

美国法官裁定五角大楼将 Anthropic 列入黑名单违法，Anthropic 在诉讼中获胜。该裁决解除其联邦业务限制，对 AI 国防采购及行业监管具有标志性意义。

- [Anthropic Just Beat The Pentagon in Court](https://www.ibtimes.com/anthropic-just-beat-pentagon-court-judge-said-national-security-was-used-punish-its-ai-rules-3806895) `hn · 17pts`

## 5. 音乐出版商起诉 Anthropic 侵犯版权

索尼音乐与华纳查普尔等音乐出版商起诉 Anthropic，指控其“公然盗窃”版权音乐用于模型训练。这是继新闻媒体后，音乐产业对 AI 公司的又一次大规模版权诉讼，加剧内容版权争议。

- [Music publishers sue Anthropic, allege "blantant theft" of copyrighted music](https://www.axios.com/2026/08/29/anthropic-sony-warner-music-copyright) `hn · 17pts`
- [Sony Music and Warner Chappell Are Suing Anthropic](https://www.theverge.com/ai-artificial-intelligence/986438/sony-music-warner-chappell-anthropic-lawsuit-copyright) `hn · 9pts`

## 6. Anthropic 提高 Claude 订阅每周限额 25%

Anthropic 宣布将 Claude 聊天订阅的每周使用限额永久提高 25%，提升用户体验。这一调整可能反映其推理成本优化或应对市场竞争，利好普通订阅用户。

- [Claude permanently raising weekly limits by 25%](https://bsky.app/profile/anthropicbot.bsky.social/post/3muaaxs5nx424) `hn · 26pts`

## 7. Anthropic 降低 Claude Code 限额 25%

Anthropic 宣布从 9 月 14 日起将 Claude Code 的限额降低 25%，与聊天限额提升形成对比。此举可能是为了控制 API 滥用或开发成本，对依赖 Claude Code 的开发者造成限制。

- [Claude Code is going reduce limits by 25% from September 14](https://twitter.com/ClaudeDevs/status/2093742321473065266) `hn · 24pts`

## 8. Meta 计划用 AI Agents 替换员工

Meta 内部 Project OT 计划浮出水面，目标是用 AI agents 替代部分员工。该计划反映 Meta 自动化进程加速，并引发关于 AI 取代人类工作的广泛讨论。

- [Meta Project OT plan to replace employees with AI agents](https://www.thestreet.com/technology/mark-zuckerberg-shocking-message-meta-employee-layoffs-artificial-intelligence) `hn · 12pts`

## 9. 阿里发布 Qoder 代码智能工具

阿里发布 Qoder，将 Coding 定位为 AI 世界的数字执行力，强调非程序员也可使用。这是阿里在编程智能领域的最新布局，与中国大厂在代码模型方向的竞争直接相关。

- [Coding不再是程序员专属！阿里Qoder这波有点绝](https://www.qbitai.com/2026/08/480940.html) `cn:qbitai`

## 10. 华为展示 HarmonyOS 7 视觉 AI 实际应用

华为 HarmonyOS 7 视觉 AI 功能走进真实应用，支持一句话找图、低清图像增强等能力。该方案强调端侧体验，展示华为在视觉 AI 落地上的进展。
