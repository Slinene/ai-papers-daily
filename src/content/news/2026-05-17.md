# 2026-05-17 · AI 行业动态

## 1. Cerebras 上市成今年最大科技 IPO

## 2. OpenAI 通过 Plaid 连接银行账户

OpenAI 与金融 API 公司 Plaid 合作，使 ChatGPT 能够读取用户银行数据并提供理财建议。此举引发了广泛的隐私担忧，用户对 AI 获取敏感财务信息表示警惕。

- [ChatGPT 可以帮你理财了，但它也知道你的全部余额！用户：谢谢不用了](https://www.infoq.cn/article/0iIMdRwey2MQ7BHLfFj8?utm_source=rss&utm_medium=article) `cn:infoq-ai`
- [OpenAI is connecting ChatGPT to bank accounts via Plaid](https://firethering.com/chatgpt-bank-account-plaid-openai/) `hn · 101pts`

## 3. DeepSeek 发布 V4 系列开源模型

中国 AI 公司 DeepSeek 推出了新一代开源模型 DeepSeek V4 及 V4-Flash 变体，在推理和模型引导能力上取得显著提升，被业界视为对前沿闭源模型的强有力挑战。

- [DeepSeek-V4-Flash means LLM steering is interesting again](https://www.seangoedecke.com/steering-vectors/) `hn · 207pts`
- [DeepSeek V4: The Open-Source Model Frontier Labs Feared](https://helloai.com/articles/deepseek-v4-open-source-frontier-parity) `hn · 77pts`

## 4. Anthropic 在 AWS 推出 Claude Platform

Anthropic 正式发布 Claude Platform on AWS，允许企业直接在 AWS 基础设施上部署和管理 Claude 模型，简化了企业访问与控制流程。

- [Anthropic 推出 Claude Platform on AWS](https://www.infoq.cn/article/mjFmXfhf29SA5UFhr2QV?utm_source=rss&utm_medium=article) `cn:infoq-ai`

## 5. 阿里健康发布医疗 AI「氢离子」

阿里健康推出面向医生的 AI 决策支持系统「氢离子」，强调基于顶级医学期刊的证据源，旨在提升临床诊疗的准确性与效率。

- [中国500万医生的新AI：顶刊独家联手，卷的就是证据源](https://www.qbitai.com/2026/05/418491.html) `cn:qbitai`

## 6. Meta 收集员工键鼠数据训练 AI

Meta 开始捕获员工的鼠标移动和键盘输入数据，用于 AI 模型训练，此做法立即引发内部和外部的强烈争议，被指严重侵犯员工隐私。

- [Meta to Start Capturing Employee Mouse Movements, Keystrokes for AI Training](https://daringfireball.net/linked/2026/05/10/meta-employee-spyware) `hn · 17pts`

## 7. OpenAI Codex 集成至 ChatGPT 移动端

OpenAI 将 Codex 功能扩展到 ChatGPT 移动应用，新增远程 SSH、hooks 和编程化令牌支持，大幅提升了企业自动化任务的处理能力。
