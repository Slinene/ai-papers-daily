## 3. Claude Code 支持并行 AI worker

Anthropic 宣布升级 Claude Code Projects，支持并行运行多个 AI worker，提升开发流程效率。这是 Claude Code 在开发者工具上的重要更新。

- [Anthropic upgrades Claude Code Projects to run parallel AI workers](https://claude.com/resources/articles/projects-redesigned) `hn · 98pts`

## 4. DeepSeek 开放全家桶 API

DeepSeek 官方宣布开放其 App 全家桶 API，用户可自由组合调用官方功能，大幅提升集成灵活性，是 DeepSeek 平台化的重要一步。

- [突发！DeepSeek开放全家桶API](https://www.qbitai.com/2026/11/510003.html) `cn:qbitai`

## 5. Llama.cpp 发布 v1.0

开源推理框架 Llama.cpp 迎来 v1.0 里程碑，并推出原生 macOS 应用，标志着项目成熟度提升。

- [Llama.cpp hits v1.0 with a native app for macOS](https://huggingface.co/blog/ggml-org/llama-cpp-v1) `hn · 25pts`
