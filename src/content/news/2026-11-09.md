# 2026-11-09 · AI 行业动态

## 1. OpenAI 完成 110 亿美元新融资

OpenAI 本轮追加融资到账 110 亿美元，估值达 1.25 万亿美元，但金额不到原计划一半，反映投资人对 AI 泡沫的态度趋于谨慎。此前传闻的巨额融资未能完全兑现，硅谷资本开始收缩对头部 AI 公司的押注。

- [OpenAI raises $11B at a $1.25T valuation](https://247wallst.com/investing/2026/11/07/openai-just-raised-11-billion-at-a-1-25-trillion-valuation-below-the-1-4-trillion-it-first-sought/) `hn · 186pts`
- [OpenAI reportedly raises an additional $11B at a $1.25T valuation](https://techcrunch.com/2026/11/06/openai-reportedly-raises-an-additional-11-billion-at-a-1-25-trillion-valuation/) `hn · 5pts`

## 2. Claude Code 泄露密码并被高盛禁用

Claude Code 的“Don't Ask Again”机制导致 1122 个公开 GitHub 仓库泄露密码等敏感信息，引发安全担忧。高盛随即要求旗下银行家和交易员停止使用 Claude Code，凸显企业级 AI 编码工具的安全审查压力。

- [Goldman Sachs is pulling Claude Code from its bankers and traders](https://www.thestateofai.com/news/goldman-sachs-claude-code-traders-bankers) `hn · 738pts`
- [Claude Code's "Don't Ask Again" exposes passwords in 1,122 public GitHub files](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again) `hn · 600pts`

## 3. Anthropic 签署 34 亿美元天然气发电协议

Anthropic 与电力公司达成 34 亿美元协议，建设燃气发电厂为其数据中心供电。此举显示 AI 训练和推理的能源需求持续攀升，头部实验室正通过自建或包销电力保障算力。

- [Anthropic strikes $3.4B deal to generate gas-fired power for data centres](https://www.ft.com/content/41bf5c6a-9735-4f1a-a8e3-2bcccad58ba0) `hn · 40pts`

## 4. 英伟达发布 Cosmos 3 开源世界模型

英伟达在 Hugging Face 发布 Cosmos 3 开源模型系列，面向交互式世界模拟和机器人训练。该发布与其在终端侧展出的 MoE 智能体共同推动物理 AI 和世界模型落地。

- [New NVIDIA Cosmos 3 Open Models for Interactive World Simulation](https://huggingface.co/blog/nvidia/cosmos-interactive-world-simulation) `blog:hf-blog`

## 5. 苹果 CEO 施压软件主管加快 AI 战略

报道称苹果 CEO 蒂姆·库克正向软件负责人施压，要求制定更雄心勃勃的 AI 战略，应对 Siri 和端侧智能的竞争压力。苹果在生成式 AI 领域落后于 OpenAI、Google 和 Meta，内部正试图加速追赶。

- [Apple CEO Presses Software Chief to Pursue More Ambitious AI Strategy](https://www.bloomberg.com/news/newsletters/2026-11-08/apple-explores-turning-siri-ai-into-chatgpt-dots-like-agent-ios-28-shake-up) `hn · 35pts`

## 6. 开源项目让 DeepSeek 284B 在 64GB 内存运行

Llama-modchip 项目实现 2840 亿参数的 DeepSeek 模型在 64GB 内存、无 GPU 环境下运行，大幅降低大模型本地推理门槛。该方案验证了通过内存芯片和量化技术部署超大模型的可行性。

- [Llama-modchip: 284B DeepSeek on 64GB RAM, no GPU](https://github.com/synchopate/llama-modchip) `hn · 412pts`
