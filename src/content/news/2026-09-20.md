# 2026-09-20 · AI 行业动态

## 1. 华为打造AI算力底座

华为常务董事汪涛强调，打造AI算力底座不能只靠芯片，软件生态至关重要。华为的CANN平台已跨过拐点，正在补齐软件生态短板，以支撑其AI芯片竞争力。

- [华为汪涛：华为要打造AI算力底座，只做好一颗芯片远远不够](https://www.qbitai.com/2026/09/492476.html) `cn:qbitai`

## 2. 阿里Qwen 3.8生成网页

阿里Qwen 3.8模型展示了快速交付网页的能力，27B参数模型可生成设计图和前端代码。该演示表明中小模型在自动化开发任务上具备实用性，不过后端部分仍需人工。

- [27B模型分分钟交付网页，Qwen 3.8还是太能了](https://www.qbitai.com/2026/09/492573.html) `cn:qbitai`

## 3. 智谱GLM编码代理隐私争议

智谱的GLM编码代理ZCode被曝会在用户不知情的情况下上传Git历史，引发隐私争议。这一行为可能涉及敏感代码泄露，值得开发者警惕。

- [ZCode, the GLM coding agent, silently uploads your Git history](https://tokenstead.ai/guides/zcode-silent-git-history-upload) `hn · 261pts`

## 4. Anthropic Claude Code支持AGENTS.md

Anthropic为Claude Code增加了AGENTS.md支持，当目录中没有Claude.md时自动读取AGENTS.md。这简化了开发者配置流程，提升了与其他代理工具的兼容性。

- [Claude Code now reads AGENTS.md if there is no Claude.md](https://code.claude.com/docs/en/changelog) `hn · 717pts`
- [Anthropic finally adds AGENTS.md support to Claude Code](https://twitter.com/trq212/status/2101009392611278961) `hn · 51pts`

## 5. OpenAI GPT-6 Astra破译一战密码

OpenAI的GPT-6 Astra模型成功破译了一个一战时期的德国无线电密码，显示出强大的推理和模式识别能力。该成就为LLM在密码学等专业领域的应用提供了实例。

- [GPT-6 Astra Solves a WWI German Radio Cipher](https://www.prinzai.com/p/gpt-6-astra-solves-a-wwi-german-radio) `hn · 377pts`

## 6. OpenAI用LLM设计芯片

OpenAI利用其自研LLM设计了Jalapeño芯片，展示了AI在硬件设计中的潜力。这表明LLM可以辅助工程师完成部分芯片设计工作，可能改变传统设计流程。

- [How OpenAI Used Its Own LLMs to Design Its Jalapeño Chip](https://spectrum.ieee.org/llms-for-chip-design) `hn · 199pts`
