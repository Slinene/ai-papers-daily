# 2026-11-02 · AI 行业动态

## 1. Anthropic 收紧 Claude 使用：禁止逆向游戏

多源报道 Anthropic 正采取措施阻止 Claude 被用于逆向工程或克隆视频游戏，甚至被指“暗改 Harness”以禁止相关行为。该调整反映了模型提供方对版权与内容生成边界的主动控制。

- [Anthropic's Claude AI blocks video game cloning and reverse-engineering](https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropics-ai-model-is-now-blocking-attempts-at-video-game-recreation-and-cloning-users-also-claim-non-malicious-generic-reverse-engineering-tasks-are-blocked) `hn · 73pts`

## 2. Anthropic Mythos 级模型疑似泄漏至 Hugging Face

网传 Anthropic 的“Mythos”系列模型检查点在 Hugging Face 出现，有报道称权重已被下载约 5000 次，URL 随后因安全顾虑被删除。该泄漏事件引发了对前沿模型安全与访问控制的关注。

- [GPT-6.2 Astra开启灰测！Claude Mythos 5.5同日曝光](https://www.qbitai.com/2026/11/507082.html) `cn:qbitai`
- [Anthropic's Mythos-class model allegedly leaked on Hugging Face](https://news.ycombinator.com/item?id=50326727) `hn · 45pts`
- [Alleged Mythos Class Anthropic Checkpoint Leak](https://huggingface.co/burner22/numbat) `hn · 35pts`

## 3. Anthropic 阻止用户涉足训练更大模型

Hacker News 热帖称 Anthropic 正阻止用户从事任何与训练更大模型相关的活动，或为控制竞争与算力消耗。该政策可能影响基于 Claude 的蒸馏和扩展研究。

- [Anthropic blocks users for anything touching training larger models](https://twitter.com/jiahaoshao1/status/2116475922190922088) `hn · 464pts`

## 4. DeepSeek 开源 dsh-superagent 编码智能体

DeepSeek 开源了编码智能体 dsh-superagent，据称该 Agent 底座架构大部分代码由 AI 自身构建，能够自主发现 Bug 并提交 PR。这延续了 DeepSeek 的开源性价比路线。

- [刚刚，DeepSeek重磅开源：Agent底座架构！](https://www.qbitai.com/2026/10/506904.html) `cn:qbitai`
- [DeepSeek open-sources dsh-superagent, a coding agent largely built by agents](https://github.com/deepseek-ai/dsh-superagent-prototype) `hn · 11pts`

## 5. OpenAI 灰度测试 GPT-6.2 Astra

中文科技媒体称 GPT-6.2 Astra 已开启灰测，同日 Anthropic 的 Claude Mythos 5.5 也曝光。该消息显示 OpenAI 下一代模型进入早期用户验证阶段。

- [GPT-6.2 Astra开启灰测！Claude Mythos 5.5同日曝光](https://www.qbitai.com/2026/11/507082.html) `cn:qbitai`

## 6. OpenAI 调整 ChatGPT Pro 额度并合并 Codex 限制

有报道称 ChatGPT Pro 订阅额度翻倍，但被解读为对用户的让步而非福利；同时 OpenAI 正在合并 ChatGPT 与 Codex 的使用限额。这些调整引发用户对订阅策略变化的讨论。

- [ChatGPT Pro 额度翻倍：是让步，不是福利？](https://www.infoq.cn/article/WpTNht7guarWEyejJFV6?utm_source=rss&utm_medium=article) `cn:infoq-ai`
- [ChatGPT and Codex usage limits merging](https://help.openai.com/en/articles/20001625-understanding-chatgpt-and-codex-usage-limits) `hn · 223pts`

## 7. 百度 AI API 降价至千次 4.9 元

百度搜索 AI API 定价降至每千次 4.9 元，低于 DeepSeek 的同类服务。这一价格策略意在争夺开发者与中小企业市场，加剧中国大模型 API 竞争。

- [百度搜索 AI API 千次仅需 4.9 元，低于 DeepSeek](https://www.infoq.cn/article/HJgTwfsPAugNBJ2jUefj?utm_source=rss&utm_medium=article) `cn:infoq-ai`

## 8. 小米开源 150 元 AI 小玩意

小米开源了一款售价约 150 元的 AI 设备，可指挥 Agent 执行任务并控制智能家居，市场反响热烈导致配件涨价。该产品将大模型能力引入低成本硬件。

- [小米开源了个150元的AI小玩意，火到配件都涨价了](https://www.qbitai.com/2026/11/507107.html) `cn:qbitai`

## 9. Mistral Large 4 在 Hugging Face 发布

Mistral 最新大模型 Mistral Large 4 已登陆 Hugging Face，代号“Le Chonk”。该发布延续了欧洲开源模型阵营的竞争力。

- [Welcome Le Chonk: Mistral Large 4 on Hugging Face](https://huggingface.co/blog/mistral-large4) `blog:hf-blog`

## 10. Apple 开源语音与决策模型

Apple 在 Hugging Face 上发布 AnySpeechRecognizer 和 AnyDecisionModel，用于语音识别与决策任务，面向 Apple 平台。这显示苹果在开源模型生态上的新动作。

- [Introducing AnySpeechRecognizer and AnyDecisionModel: Open Models for Speech and Decisions on Apple Platforms](https://huggingface.co/blog/anydecisionmodel) `blog:hf-blog`
