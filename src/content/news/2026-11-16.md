## 3. DeepSeek 官方 App API 开放，价格优势显著

DeepSeek 将官方 App 的全套能力（包括联网搜索）通过 API 开放，其联网搜索价格不到 OpenAI 和 Claude 的 8%。这一动作加剧了 API 市场价格竞争，有望吸引更多开发者。

## 4. 腾讯混元发布 Hy4 flash 模型

腾讯混元推出 Hy4 flash 模型，单任务成本仅为 Hy4 的 5%。该模型在性能和成本之间取得平衡，可能推动企业大规模采用。

- [腾讯混元发布Hy4 flash，单任务成本仅为 Hy4 的 5%](https://www.infoq.cn/article/ejVJGwMvIIvplY8yio5r?utm_source=rss&utm_medium=article) `cn:infoq-ai`

## 5. 斯坦福等机构发布“史上最严”湿实验预测基准

斯坦福、哈佛、康奈尔等十余家顶尖机构联合发布湿实验预测基准，即使推理拉满、算力翻 5 倍也无法提升模型表现。该基准暴露出当前 AI 模型在真实科学实验预测上的局限性。

- [「史上最严」湿实验预测基准发布！推理拉满、算力翻5倍也白搭](https://www.qbitai.com/2026/11/510232.html) `cn:qbitai`

## 8. llama.cpp v1.0.0 发布

## 10. 亚马逊 Mitra-v2 表格基础模型扩展

亚马逊科学团队扩展 Mitra-v2 的合成预训练混合数据，使其能零样本适应新表格，并在 TabArena 基准上领先单模型。该研究推动表格基础模型的前沿，降低定制成本。

- [Mitra-v2: Scaling synthetic pretraining for tabular foundation models](https://www.amazon.science/blog/mitra-v2-scaling-synthetic-pretraining-for-tabular-foundation-models) `blog:amazon-science`
