# 2026-08-20 · AI 行业动态

## 1. OpenAI 暂停前沿强化学习训练两周

OpenAI 已暂停部分前沿强化学习训练两周，以加强安全与对齐；官方强调安全准备度已成为前沿扩展节奏的决定因素。该动作与“放缓训练”信号一致，显示公司对前沿模型风险更谨慎。

- [not much happened today](https://news.smol.ai/issues/26-08-18-not-much/) `blog:smol-ai-news`
- [OpenAI pauses frontier model training](https://twitter.com/sama/status/2089787807611195475) `hn · 25pts`
- [OpenAI Is Slowing Down Its AI Training](https://time.com/article/2026/08/18/openai-slowing-training/) `hn · 14pts`

## 2. OpenAI 解散灾难性风险评估团队

HN 讨论指出 OpenAI 已解散原本负责评估灾难性模型风险的团队；这是继暂停训练后又一次安全组织调整。外界担忧其削弱了对最坏情况的前置把关。

- [OpenAI disbanded the team that assessed catastrophic model risks](https://thenextweb.com/news/openai-preparedness-team-disbanded-ipo-streamlining) `hn · 32pts`

## 3. OpenAI 算力扩张：4+GW NVIDIA 与 8GW 俄亥俄园区

OpenAI 正在推进电力与算力基础设施，承诺 4+GW NVIDIA 容量，并计划到 2032 年建成 8GW 俄亥俄园区。该布局强调纵向整合，支撑大规模训练与推理。

- [not much happened today](https://news.smol.ai/issues/26-08-17-not-much/) `blog:smol-ai-news`

## 4. Google 发布 Gemini 3.7 Flash

Google 在 3.6 Flash 后仅三周就发布 Gemini 3.7 Flash，面向编码、网页开发、知识工作与智能体流程；推出价降低 50%，性能进一步改善。快速迭代与降价加剧模型竞争。

- [not much happened today](https://news.smol.ai/issues/26-08-13-not-much/) `blog:smol-ai-news`

## 5. 智谱 Z.ai 发布 GLM-5.3

Z.ai 推出 GLM-5.3，聚焦编码和网络安全，在智能体与安全基准上提升显著；通过放大后训练而非更大底座模型实现。模型在安全与代码场景具备竞争力。

- [not much happened today](https://news.smol.ai/issues/26-08-14-cursor-xai/) `blog:smol-ai-news`

## 6. 华尔街实测：千问办公 Agent 综合排名第一

华尔街对 8 款全球主流 Agent 进行实测，阿里千问在办公场景综合排名第一；成本正成为 Agent 商业化的重要考量。千问在办公智能体性价比上获得认可。

- [华尔街实测8款全球主流Agent：千问办公综合排名第一](https://www.qbitai.com/2026/08/476070.html) `cn:qbitai`

## 7. Claude Code 为仅 Windows 打印机编写 macOS 驱动

用户借助 Claude Code 为仅支持 Windows 的 HP Laser 1008a 打印机编写原生 macOS 驱动，并成功打印。该案例展示 Claude Code 在硬件驱动级代码生成上的能力。

## 9. 全球首个人形机器人自主乒乓球完整对局亮相 WRC

- [全球首个人形机器人自主乒乓球完整对局亮相2026世界机器人大会](https://www.qbitai.com/2026/08/475907.html) `cn:qbitai`
