# 2026-07-14 · AI 行业动态

## 1. OpenAI 发布 GPT-5.6 系列，分层定价与性能提升

OpenAI 推出 GPT-5.6 系列，包含 Sol、Terra、Luna 三个型号，并引入 Max 和 Ultra 努力级别，定价每百万 token 1 至 5 美元。上线 ChatGPT、Codex 和 API，相比前代推理速度提升 2.2 倍，成本下降 27%。

## 2. OpenAI 安全主管在 GPT-5.6 发布后离职

在 GPT-5.6 发布当天，OpenAI 安全主管突然离职，成为两年内离开的第六位安全负责人，引发外界对 OpenAI 安全治理的担忧。

- [GPT-5.6刚发布，OpenAI安全主管就跑路了？？](https://www.qbitai.com/2026/07/448825.html) `cn:qbitai`

## 3. xAI 发布 Grok 4.5，强调编程与代理能力

xAI 公开推出 Grok 4.5，主打编程和代理能力，定位为性价比前沿模型，Elon Musk 称其为“Opus 级”但速度更快，安全漏洞发现表现优于 Anthropic。

- [not much happened today](https://news.smol.ai/issues/26-07-08-grok-45/) `blog:smol-ai-news`
- [Grok 4.5 and GPT5.6 beat Anthropic for finding security vulnerabilities in PRs](https://docs.damsecure.ai/blog/pr-review-security-benchmark/) `hn · 10pts`

## 4. Anthropic 延长 Fable 5 访问权限至 7 月 19 日

Anthropic 宣布将 Claude Fable 5 的访问期限再延长一周，但社区对其数据使用和定价策略的质疑持续发酵，称其“黑心账本”难以隐藏。

- [Fable 5 访问权限再延一周，但Anthropic 的“黑心账本”越来越藏不住了](https://www.infoq.cn/article/eRwadJmvQIvuqaDZKBiz?utm_source=rss&utm_medium=article) `cn:infoq-ai`
- [Claude Fable 5 access extended through July 19](https://xcancel.com/claudeai/status/2076351399999557669#m) `hn · 9pts`

## 5. Claude Code 被指过度消耗 token 引发社区批评

开发者发现 Claude Code 在读取提示前发送 33k token，而竞品 OpenCode 仅需 7k，Zig 语言创始人公开批评 Anthropic 的营销不实，引发广泛讨论。

- [Zig Creator Calls Spade a Spade, Anthropic Blows Smoke](https://raymyers.org/post/zed-creator-calls-spade-a-spade/) `hn · 1428pts`
- [Claude Code sends 33k tokens before reading the prompt; OpenCode sends 7k](https://systima.ai/blog/claude-code-vs-opencode-token-overhead) `hn · 686pts`

## 6. 微软为开发者推出 Claude Code 与 GitHub Copilot CLI 集成

微软在 2026 年初向内部团队推出 Claude Code 和 GitHub Copilot CLI 的集成方案，旨在提升开发者命令行体验，相关研究已被公开分享。

- [A Study of Microsoft's Early 2026 Rollout of Claude Code and GitHub Copilot CLI](https://arxiv.org/abs/2607.01418) `hn · 42pts`

## 7. 蚂蚁集团开源两大安全框架应对 Claude Code 风险

为应对 Claude Code 等 agent 带来的安全挑战，蚂蚁安全团队最新开源了两大安全框架，提供从代码生成到依赖分析的全链路防护。

- [Claude Code砸的坑，蚂蚁安全在尝试填上](https://www.qbitai.com/2026/07/448925.html) `cn:qbitai`

## 9. 国产 Agent 专用搜索产品登顶 Product Hunt

一款由中国团队开发的 Agent 专用搜索引擎在 Product Hunt 获得当日冠军，主打更省 token 且精准度高，专为 AI agent 的信息检索优化。

- [Agent专用搜索登顶Product Hunt，Token更省搜得更准](https://www.qbitai.com/2026/07/449327.html) `cn:qbitai`

## 10. 浪潮信息发布单柜 4 万 Agent 硬件方案与多模融合超节点

浪潮信息推出 CPU 原生液冷整机柜，单柜可承载 4 万个 AI agent，同时发布多模融合超节点，意图将高性能计算与大规模 agent 部署结合。
