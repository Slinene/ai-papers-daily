## 3. 高盛禁止交易员使用 Claude Code

高盛出于安全与合规考虑，从银行家和交易员的工作环境中移除 Claude Code。此事反映金融机构对 AI 编程工具接入敏感数据的谨慎态度，也凸显企业级 AI 部署的安全挑战。

- [Goldman Sachs is pulling Claude Code from its bankers and traders](https://www.thestateofai.com/news/goldman-sachs-claude-code-traders-bankers) `hn · 888pts`

## 4. Google Gemini 将个人 Drive 文件和邮件发送给人工标注引发隐私争议

Google Gemini 被曝将用户的个人 Drive 文件和邮件内容路由给人工标注员，用于改进模型。这一做法引发用户对隐私边界的强烈质疑，凸显 AI 训练数据收集与个人数据保护之间的冲突。

- [Google Gemini routes personal Drive files and emails to human annotators](https://github.com/thisisme6598/gemini_files/) `hn · 577pts`

## 5. Google 发布面向 Agent 时代的新 TPU 8tx 和 8i Max

Google 推出两款专为 AI Agent 工作负载设计的新 TPU：8tx 和 8i Max，强调在推理和训练上的性能与效率提升。新硬件旨在应对日益增长的智能体计算需求，巩固 Google 在 AI 芯片领域的竞争力。

- [Our newest TPUs: 8tx and 8i Max, built for the agentic era](https://blog.google/innovation-and-ai/infrastructure-and-cloud/global-network/tpu-8i-max-and-8tx/) `hn · 27pts`

## 6. Meta 发布低成本模型 Muse Ember，对标 Claude Haiku 5.5

Meta 推出新模型 Muse Ember，声称成本仅为 Claude Haiku 5.5 的三分之一，同时保持竞争力。该模型定位轻量级、低成本，可能对中小型应用和边缘部署产生吸引力。

- [成本仅1/3！Meta 新模型 Muse Ember 硬刚 Claude Haiku 5.5](https://www.infoq.cn/article/Ou4l4aD7zvUzXWXsWJfY?utm_source=rss&utm_medium=article) `cn:infoq-ai`

## 7. 腾讯混元发布开源多模态 Agent 模型 Hy4 及 WorkBuddy

腾讯混元宣布 Hy4 成为最强开源模型之一，并搭配 WorkBuddy 提升多模态 Agent 交付能力。该模型强调多模态理解与任务执行，展现腾讯在开源 AI 生态中的布局。

- [腾讯混元跻身最强开源模型！一手实测Hy4：搭配WorkBuddy，多模态Agent交付力拉满](https://www.qbitai.com/2026/11/507843.html) `cn:qbitai`

## 8. 阿里千问办公 2.0 发布，支持多人与 Agent 协作的 Team Agent

千问办公 2.0 正式发布，引入首个支持多人与 Agent 协作的 Team Agent 功能。该产品将 AI Agent 从个人助手扩展到团队协作场景，提升办公自动化水平。

- [千问办公2.0发布，首个支持多人与Agent协作的Team Agent来了](https://www.qbitai.com/2026/11/508694.html) `cn:qbitai`

## 9. DeepSeek Harness 日活 154 万，官方用 Token 激励插件开发者

DeepSeek Harness 平台日活跃用户达 154 万，官方开始向插件作者发放 Token 以激励开发者构建 Agent 生态。此举旨在通过开发者社区扩大 DeepSeek 的工具调用与智能体能力覆盖。

- [DeepSeek Harness 日活154万，官方开始给插件作者发Token：Agent 生态要靠开发者了](https://www.infoq.cn/article/Y7lTO7Q1M8oN5JhxhirK?utm_source=rss&utm_medium=article) `cn:infoq-ai`

## 10. ChatGPT 桌面版被发现转发 SSH Agent 到远程机器

安全研究人员发现 ChatGPT 桌面版会转发本地 SSH Agent 到远程机器，可能导致远程代码执行时使用本地 SSH 凭据，存在推送私有仓库等风险。该漏洞引发对 AI 桌面应用安全设计的担忧。

- [ChatGPT Desktop forwards your SSH agent to remote machines](https://news.ycombinator.com/item?id=50422628) `hn · 208pts`
