# 2026-08-03 · AI 行业动态

## 1. 华为诺亚开源 MindMemOS 记忆操作系统

华为诺亚方舟实验室开源 MindMemOS，这是一个面向 AI Agent 的可迁移、自演进记忆操作层，旨在解决大模型“用完即忘”的问题，让 Agent 的记忆与技能能够持续进化。

- [AI不再用完即忘：华为诺亚开源MindMemOS，记忆和Skill一起进化](https://www.qbitai.com/2026/08/464835.html) `cn:qbitai`

## 2. 阿里发布 Qwen3.8：2.4T 参数，自主编程构建 Agent

阿里巴巴正式发布 Qwen3.8，模型规模达 2.4T，展现出强大的自主编程能力，仅用 16 天就编写出一个名为 Hermes 的 AI Agent，体现了模型在复杂任务规划与代码生成上的突破。

- [阿里Qwen3.8正式发布：2.4T规模，自主编程16天搓出一个Hermes Agent](https://www.infoq.cn/article/XG7GeBthC6eKO5Rejf02?utm_source=rss&utm_medium=article) `cn:infoq-ai`

## 3. DeepSeek-V4-Flash API 开启公测

DeepSeek 推出 DeepSeek-V4-Flash API 的公测版本，在未改变架构和规模的情况下，通过后训练技术实现了显著性能跃升，在 Terminal-Bench 上获得 82 分。

## 5. OpenAI 大幅降低 GPT-5.6 系列价格
