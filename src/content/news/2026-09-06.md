# 2026-09-06 · AI 行业动态

## 1. OpenAI 发布 GPT-6 Astra，刷新编码与计算机使用 SOTA

OpenAI 推出 GPT-6 Astra，定位为史上最大 LLM 发布，在计算机使用和编码任务上达到新 SOTA，token 单价上涨 2.5 倍但单任务成本更低。陶哲轩对 GPT-6 在孪生素数问题上直接给出正确答案表示惊讶，认为关键可能不在答案本身。

## 3. Anthropic Claude 完成费马大定理首个完整形式化证明

## 4. OpenAI 与 Anthropic 同日宕机，原因未公开

OpenAI 与 Anthropic 同日发生服务中断，但两家公司均未公开具体原因。这一神秘宕机事件引发对 AI 基础设施稳定性和透明度的质疑。

## 5. Spotify Portal 将 Claude Code token 用量削减 90%

Spotify 工程团队发布 Portal 工具，聚焦于减少 AI 编码代理的 I/O 开销，使 Claude Code 的 token 用量下降 90%。该工具揭示编码 agent 大部分工作并非思考而是 I/O，为降本提效提供新思路。

- [Portal by Spotify cut my Claude Code token usage by 90%](https://engineering.atspotify.com/2026/9/portal-by-spotify-cut-my-claude-code-token-usage-by-90/) `blog:spotify-eng`
- [Portal by Spotify cut my Claude Code token usage by 90%](https://engineering.atspotify.com/2026/9/portal-by-spotify-cut-my-claude-code-token-usage-by-90) `hn · 252pts`

## 6. 阿里被曝早已布局循环 Transformer

GPT-6 带火了循环 Transformer 技术，阿里被曝已在相关方向提前布局，拥有两篇顶会论文。这一技术路线有望在长序列建模和推理效率上带来突破。

- [GPT-6带火循环Transformer，阿里早已布局](https://www.qbitai.com/2026/09/484726.html) `cn:qbitai`

## 7. 趋境科技与摩尔线程战略合作，国产异构 AI Token 方案

趋境科技与摩尔线程达成战略合作，推出基于国产 GPU 的高品质 AI Token 异构方案，宣称性价比超越国际先进算力。此举展示了国产芯片和系统在 AI 推理侧的生产级性能。

- [趋境科技与摩尔线程达成战略合作，高品质 AI Token 国产异构方案性价比超越国际先进算力](https://www.qbitai.com/2026/09/484547.html) `cn:qbitai`

## 8. 伯克利与 MIT 开源 FreeToken，消费级 GPU 跑 35B 模型

伯克利和 MIT 联手开源 FreeToken，使 RTX 4060 能以每秒 39 token 的速度运行 35B 模型。该框架通过 token 级优化大幅降低大模型本地推理门槛。

- [RTX 4060 跑 35B 模型，每秒 39 Token？伯克利、MIT 联手开源 FreeToken](https://www.infoq.cn/article/tij5T0vJ1Yk0s7Uov7SE?utm_source=rss&utm_medium=article) `cn:infoq-ai`

## 9. Nvidia 收购 HuggingFace 后，llama.cpp 作者回应未来

Nvidia 收购 HuggingFace 消息传出后，llama.cpp/ggml 作者 Georgi Gerganov 就项目未来发表看法，引发社区关注。这一收购可能重塑开源 AI 生态与推理工具链格局。

- [Georgi Gerganov on llama.cpp/ggml future after Nvidia acquisition of HuggingFace](https://twitter.com/ggerganov/status/2095897173376618881) `hn · 76pts`

## 10. Meta 裁员目标提至 60%，30% 工程师转标注员

Meta 被曝将裁员目标提高到 60%，并已将 30% 工程师转为数据标注员，以加速 AI 转型。这一激进调整凸显大型科技公司对 AI 人才结构的重塑。

- [Meta new layoff goal of 60% to AI after moving 30% engineers to labelers](https://blog.pragmaticengineer.com/the-pulse-meta-wanted-to-reduce-teams-by-60-because-of-ai/) `hn · 23pts`
