# 2026-09-03 · AI 行业动态

## 1. Anthropic 发布 Claude Fable 5.1 与 Mythos 5.1

Anthropic 同时发布 Claude Fable 5.1 和 Claude Mythos 5.1，两者共享基础权重，但在安全护栏和路由上有所不同。新模型在多项基准上登顶，缓存价格降低 75%，输出 token 增多，并引入反蒸馏机制。

- [Claude最强Fable 5.1发布！8项屠榜，最高降价45%，反蒸馏机制上线](https://www.qbitai.com/2026/09/482652.html) `cn:qbitai`
- [Claude Fable 5.1 and Claude Mythos 5.1](https://news.smol.ai/issues/26-09-01-claude-mythos-51/) `blog:smol-ai-news`
- [[AINews] Claude Fable/Mythos 5.1: new SOTA model, 75% cache price cut but 70% more output tokens](https://www.latent.space/p/ainews-claude-fablemythos-51-new) `blog:latent-space`
- [Claude Fable 5.1 and Claude Mythos 5.1](https://www.anthropic.com/claude-fable-and-mythos-5-1) `hn · 1385pts`

## 2. Google DeepMind 发布 Gemini 3.8 Flash 系列

Google DeepMind 上线 Gemini 3.8 Flash 和 3.8 Flash Cyber 的模型卡片，推出两个 Gemini 3.8 系列高效模型。此次发布将 Gemini 3.8 系列扩展到 Flash 版本，引发 HN 大量讨论。

- [Gemini 3.8 Flash and 3.8 Flash Cyber](https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/) `hn · 939pts`

## 3. Meta 发布 Muse Spark 1.3，挑战 GPT-5.6-Sol

Meta 发布 Muse Spark 1.3，据称性能匹配 GPT-5.6-Sol，并提供超过 90% 的训练折扣，被视为 Meta 在前沿模型领域的重要回归。该模型在 HN 上获得大量关注。

- [[AINews] Muse Spark 1.3 matches GPT-5.6-Sol, confirming Meta Superintelligence as the newest Frontier Lab, >90% discount for training](https://www.latent.space/p/ainews-muse-spark-13-matches-gpt) `blog:latent-space`
- [Muse Spark 1.3](https://developer.meta.com/ai/models/muse-spark/) `hn · 495pts`

## 4. 阿里更新旗舰模型 Qwen3.8-Max

阿里发布旗舰模型 Qwen3.8-Max，重点提升前端编程能力，在相关基准上跃居全球第一。这一更新显示通义千问系列在代码智能上的持续投入。

- [阿里更新旗舰模型Qwen3.8-Max，前端编程能力跃居全球第一](https://www.qbitai.com/2026/09/483101.html) `cn:qbitai`

## 5. 蚂蚁 OmniTable 获 VLDB 工业最佳论文

蚂蚁集团推出统一宽表系统 OmniTable，一套宽表可处理 35PB 语料，数据清洗效率提升 5.6 倍，论文获评 VLDB 2026 工业赛道最佳论文。该工作展示了大规模数据基础设施的工程能力。

- [还在为大模型洗数据熬夜？蚂蚁拿下VLDB工业最佳论文，一套宽表搞定35PB语料，效率狂飙5.6倍](https://www.qbitai.com/2026/09/483104.html) `cn:qbitai`

## 6. Cursor 推出面向智能体的 GitHub 替代 Origin

Anysphere 旗下 Cursor 推出 Origin，一个面向 AI 智能体的代码托管平台，定位为 GitHub 替代方案。此举标志着 AI 原生开发工具正在向协作与代码托管领域延伸。

- [Cursor 推出 Origin：面向智能体的 GitHub 替代方案](https://www.infoq.cn/article/labxcNbT15HapoWw69lq?utm_source=rss&utm_medium=article) `cn:infoq-ai`

## 7. Hugging Face 发布 200+ WebGPU 内核

Hugging Face 发布 @huggingface/kernels，包含 200 多个 WebGPU 内核，用于在浏览器中本地运行 AI 模型。该项目将提升 Web 端 AI 推理性能，推动去中心化的本地 AI 应用。

- [Introducing @huggingface/kernels: 200+ WebGPU Kernels for Local AI](https://huggingface.co/blog/webgpu-kernels) `blog:hf-blog`

## 8. 苹果在 OpenAI 诉讼中出示前员工 MacBook 证据

苹果在针对 OpenAI 的诉讼中，从一名前员工的 MacBook 中提取了“令人震惊的证据”，具体内容尚未公开。该事件涉及 AI 公司间的人才流动与商业机密争议，引发广泛关注。

- [Apple reveals 'shocking evidence' from ex-employee's MacBook in OpenAI suit](https://9to5mac.com/2026/08/31/apple-openai-forensic-macbook-evidence/) `hn · 242pts`

## 9. METR 报告 OpenAI 与 Hugging Face 黑客事件

METR 发布关于 OpenAI 和 Hugging Face 黑客事件的报告，披露相关安全漏洞与入侵细节。该报告对 AI 研究机构的安全实践提出警示，表明前沿 AI 基础设施面临的网络威胁。

- [METR Report on OpenAI / Hugging Face Hacking Incident](https://metr.org/blog/2026-08-26-openai-hugging-face-incident-investigation/#core-takeaways-about-this-incident) `hn · 101pts`

## 10. DeepSeek 开源 V4 Flash Vision 权重

DeepSeek 开放了 V4 Flash Vision 模型的权重，为模型增加视觉能力。这是 DeepSeek 在开源多模态方向的最新发布，延续其开放权重策略。
